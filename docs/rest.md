# REST

## Designing RESTful APIs

```md
<!-- create, using stream -->

POST /customers

<!-- find -->

GET /customers/{id}

<!-- update -->

POST /customers/{id}

<!-- delete -->

DELETE /customers/{id}

<!-- list -->

GET /customers

<!-- batch -->

DELETE /customers
```
